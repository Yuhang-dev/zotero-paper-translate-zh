# 翻译产物格式规范

## 1. Markdown 结构

每篇一个 `.md` 文件，结构固定（**总结在前**，用 `---` 与正文隔开）：

```markdown
# <论文中文标题>

> **原文标题**: ...
> **作者**: ...
> **出处**: ...
> **DOI**: ...
> **本文为正文中译，参考文献部分未翻译。**

---

## 文章总结

<约 500 字中文总结>

---

## 摘要
<正文翻译从这里开始，按原文章节继续：## 一、...、## 二、...>
```

要求：

- 总结必须放文件前面，用 `---` 隔开；正文从摘要/引言开始。
- 总结约 500 字，覆盖：**背景问题 → 方法/创新 → 关键结果 → 结论/意义**。

## 2. 术语与引用

- 保留原文专有名词/缩写（如 RoPE、KV-cache、SparseGPT）。
- 引用编号 `[n]` 原样保留，不翻译。

## 3. 公式规范（LaTeX，KaTeX 可渲染）

翻译中遇到数学公式，**必须用标准 LaTeX 语法**，确保在 VSCode（Markdown Preview Enhanced / Markdown+Math 等扩展，默认 KaTeX 引擎）中可正常渲染：

- **行内公式**：`$...$`，如 `$E=mc^2$`、$\delta$、$\left( \frac{1}{2} \right)$。
- **块级公式**（独立居中）：`$$...$$` 单独占一行。
- **希腊字母**：`\delta`、`\lambda`、`\mu`、`\sigma`、`\theta`、`\ell`，不要写 Unicode δλμ。
- **上下标**：多字符必须加花括号，如 `^{-1}`、`_{\ell,3}`、`^{d_1 d_2/m}`。
- **括号**：`\left( ... \right)`、`\left[ ... \right]`、`\left\{ ... \right\}` 让大小自适应。
- **范数/绝对值**：`\|\cdot\|_2`、`|x|`。
- **分数/求和/积分**：`\frac{a}{b}`、`\sum_{i=1}^n`、`\int_{-\infty}^{\infty}`、`\prod`、`\lim`、`\arg\min`、`\arg\max`。
- **矩阵/向量**：粗体 `\mathbf{W}` 或 `\boldsymbol{W}`；转置 `X^\top` 或 `X^T`；单位矩阵 `I`。
- **期望/概率**：`\mathbb{E}_{x\sim D}`、`\Pr`、`\sim`。
- 原文有编号公式 (1)(2)... 的，必须完整翻译为**块级 LaTeX 公式**；行内提到的变量用 `$...$`。
- **不要**用 Unicode 数学符号（如 ⁻¹、₂、×、≤）代替 LaTeX 命令，不要把公式写成纯文本行。
